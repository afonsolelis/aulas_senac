Aula 01: Setup do Codespaces

Todo mundo com o mesmo ambiente, funcionando

Semana 32 - 2026.2
GitHub Codespaces ambiente de desenvolvimento setup git

Agenda da Aula

  • Por que ambiente padronizado é assunto de qualidade
  • O que é o GitHub Codespaces
  • Criar a conta e abrir o primeiro Codespace
  • Git e GitHub: o básico que vamos usar o semestre inteiro
  • Deixar todo mundo com o ambiente rodando
Prática em sala

Ambiente de pé para todo mundo

  1. Criar/entrar na conta do GitHub e ativar o GitHub Student Developer Pack, se ainda não tiver.
  2. Abrir um Codespace e conferir que o terminal responde.
  3. Configurar git config user.name e user.email dentro do Codespace.
  4. Fazer um commit e um push de teste — só para confirmar que o fluxo funciona ponta a ponta.
  5. Entrar no servidor do Discord da turma.
Fim da aula: ninguém sai da sala sem um Codespace abrindo e um push funcionando.
