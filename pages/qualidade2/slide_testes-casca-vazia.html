Agenda da Aula

  • Escrever o teste antes de existir a lógica — e por que isso funciona
  • Testes unitários parametrizados a partir das classes de equivalência
  • Integração com banco real via Testcontainers
  • End-to-end contra a API
  • VCR (record & replay) para a API esportiva externa
Prática em sala

A suíte inteira, com a casca ainda vazia

  1. A aplicação continua sem lógica. Os testes vão falhar — e é exatamente esse o ponto da aula.
  2. Escrever os unitários parametrizados derivados das classes de equivalência e dos valores limite dos RNF.
  3. Escrever os testes de integração com Testcontainers: banco de verdade, subindo em container no próprio teste.
  4. Escrever os end-to-end contra a API, no ambiente que o compose da semana 39 levanta.
  5. Usar VCR / record & replay para a API esportiva externa: grava a resposta uma vez, reproduz no CI sem depender da rede.
Fim da aula: suíte completa escrita e vermelha, cobrindo os RF da RTM. Verde é assunto da semana 42.
