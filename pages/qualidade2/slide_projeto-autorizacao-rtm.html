Autenticar ≠ autorizar

“Quem é?” vem antes de “pode fazer?”

Autenticação

Token válido identifica Ana e sua sessão.

Autorização

Política decide se Ana pode ler esta matéria agora.

Token válido com assinatura vencida continua autenticado — mas não autorizado ao exclusivo.

Regra de decisão do Foot Fanatics

Permitir leitura quando o conteúdo está publicado e:

  • é PUBLICO; ou
  • é EXCLUSIVO e o usuário possui plano PREMIUM ativo no instante da requisição.

Negar por padrão qualquer combinação não explicitamente permitida.

Papel EDITOR autoriza publicar; não deve implicar automaticamente assinatura premium.

Tabela de decisão

Política central e explícita 

boolean podeLer(Principal p, Conteudo c, Clock clock) {
  if (!c.estaPublicado()) return false;
  if (c.ehPublico()) return true;
  return p != null
      && p.assinatura().plano() == PREMIUM
      && p.assinatura().estaVigente(clock);
}
Uma política única reduz divergência entre endpoints. Controller traduz a decisão; domínio/caso de uso a executa; teste a especifica.
