Agenda da Aula

  • A suíte vermelha da semana 40 é o contrato
  • Implementar a lógica até o verde — sem inventar requisito
  • Por que não se altera o teste para ele passar
  • GitHub Actions: a suíte rodando a cada pull request
  • O primeiro pipeline verde do Foot Fanatics
Prática em sala

Do vermelho ao verde, com pipeline

  1. Implementar a lógica de negócio dos escopos E1 a E4 até a suíte da semana 40 ficar verde.
  2. Regra da aula: nenhum teste novo e nenhum teste alterado. A suíte é o contrato; mudou o teste, mudou o requisito.
  3. Cada teste que passa de vermelho para verde é anotado — esse é o registro de progresso real.
  4. Configurar o GitHub Actions para rodar a suíte completa em todo pull request.
  5. Fechar a aula com o primeiro pipeline verde, rodando do zero em máquina limpa.
Fim da aula: suíte verde e pipeline rodando em PR. O sistema existe e está protegido.
