Implementação da lógica e primeiro pipeline

Fazer o vermelho virar verde — sem mexer em um teste sequer.

  1. Implementar a lógica dos escopos E1 a E4 até a suíte da aula passada ficar verde.
  2. Regra da aula: nenhum teste novo e nenhum teste alterado. A suíte é o contrato; mudou o teste, mudou o requisito.
  3. Anotar cada teste que passa de vermelho para verde — esse é o registro real de progresso.
  4. Configurar o GitHub Actions para rodar a suíte completa em todo pull request.
  5. Fazer o pipeline falhar de propósito e conferir que o PR fica bloqueado.
Fim da aula: suíte verde e primeiro pipeline rodando em pull request.
