Laboratório: o projeto é de vocês

O percurso do Foot Fanatics terminou. A partir de agora cada grupo aplica o mesmo caminho no próprio projeto.

  1. Cada grupo assume o seu projeto e refaz o percurso: personas → requisitos → arquitetura → táticas → infra → testes → implementação → RTM.
  2. Trazer para a aula o ponto onde o grupo travou — a mentoria é sob demanda, não expositiva.
  3. Manter o pipeline verde: nenhum merge sem suíte passando.
  4. Usar o Foot Fanatics como referência de como fica pronto, não como algo a copiar.
  5. Fechar cada aula com a RTM do grupo mais completa do que começou.
Fim da aula: laboratório aberto — o professor circula, cada grupo avança no próprio ritmo.
