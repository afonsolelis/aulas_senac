Capítulo 1

O que é LaTeX?

LaTeX (pronuncia-se "lá-tek" ou "lei-tek") não é um editor de texto como o Microsoft Word ou Google Docs. É um sistema de preparação de documentos de alta qualidade tipográfica. Com ele, você se concentra no conteúdo do seu trabalho, e o LaTeX cuida da formatação, garantindo um resultado profissional e consistente.

Vantagens do LaTeX para Trabalhos Acadêmicos

  • Qualidade Tipográfica: A renderização de fórmulas matemáticas, tabelas e textos é superior à da maioria dos processadores de texto.
  • Separação de Conteúdo e Estilo: Você escreve o texto em um arquivo .tex e a formatação é definida por comandos e classes, como a abntex2 para normas ABNT.
  • Automação: Geração automática de sumários, listas de figuras, referências bibliográficas e índices.
  • Estabilidade: Lida com documentos muito longos e complexos (como uma tese) de forma mais estável que editores de texto convencionais.
  • Padrão Acadêmico: É o padrão de fato em muitas áreas da ciência e engenharia para publicação de artigos e teses.
Capítulo 2

Passo Inicial: Fazendo o Fork do Template

Antes de configurar o ambiente, o primeiro passo é criar uma cópia do template oficial do TCC para a sua própria conta do GitHub. Esse processo é chamado de "Fork". Fazer um fork cria um repositório seu, vinculado ao original, onde você e seu grupo poderão trabalhar.

  1. Acesse o Repositório Template:
    Navegue até o repositório oficial: https://github.com/afonsolelis/template_tcc_senac
  2. Faça o Fork:
    No canto superior direito da página, clique no botão "Fork". O GitHub irá perguntar para qual conta você deseja copiar o repositório. Selecione sua conta pessoal.
  3. Clone o Seu Repositório:
    Após o fork ser concluído, você estará em uma nova página (github.com/SEU_USUARIO/template_tcc_senac). É deste novo repositório que você irá clonar os arquivos para seu ambiente local ou abrir no Codespaces.
Capítulo 3

Opção 1: Ambiente Local no Windows

Configurar um ambiente local lhe dá total controle e permite trabalhar offline. Recomendamos a seguinte combinação de ferramentas:

Passo 1: Instalar uma Distribuição TeX (MiKTeX)

Uma "distribuição" TeX é o motor que compila seus arquivos .tex em um PDF. Para Windows, o MiKTeX é uma excelente escolha por sua capacidade de instalar pacotes ausentes automaticamente.

  1. Acesse o site oficial do MiKTeX: miktex.org/download.
  2. Baixe o instalador para Windows.
  3. Execute o instalador. Na tela "MiKTeX Setup", você pode escolher instalar apenas para seu usuário ou para todos (requer admin).
  4. Na tela "Settings", em "Install missing packages on-the-fly", selecione "Yes". Isso é crucial para que o MiKTeX baixe pacotes como o abntex2 automaticamente quando você precisar deles.
  5. Conclua a instalação.

Passo 2: Instalar o Editor (VS Code + LaTeX Workshop)

O Visual Studio Code é um editor de código leve e poderoso. Com a extensão certa, ele se torna um ambiente LaTeX fantástico.

  1. Se ainda não tiver, baixe e instale o Visual Studio Code.
  2. Abra o VS Code, vá para a aba de Extensões (ícone de blocos ou Ctrl+Shift+X).
  3. Procure por "LaTeX Workshop" e clique em "Instalar".

Passo 3: Seu Primeiro Documento

Vamos criar um documento simples para testar o ambiente.

  1. Crie uma nova pasta no seu computador, por exemplo, TCC_Exemplo.
  2. Abra esta pasta no VS Code (File > Open Folder).
  3. Crie um novo arquivo chamado main.tex.
  4. Cole o seguinte código no arquivo:
\documentclass[12pt, a4paper]{article} \usepackage[utf8]{inputenc} \usepackage[brazil]{babel} \title{Meu Primeiro Documento LaTeX} \author{Seu Nome} \date{\today} \begin{document} \maketitle \section{Introdução} Olá, mundo! Este é meu primeiro documento gerado com LaTeX no VS Code. A fórmula de Bhaskara é: \( x = \frac{-b \pm \sqrt{b^2-4ac}}{2a} \) \end{document}

Para compilar, clique no ícone de "Play" (Build LaTeX project) que aparece no canto superior direito do VS Code, ou use o atalho Ctrl+Alt+B. Após alguns instantes, um arquivo main.pdf aparecerá na sua pasta, e o VS Code o exibirá em uma aba ao lado.

Opção Adicional: Ambiente Local com Docker

Para usuários familiarizados com Docker, esta é uma abordagem poderosa que cria um ambiente LaTeX consistente e isolado, sem instalar nada diretamente na sua máquina (além do Docker).

Pré-requisitos

  • Docker Desktop instalado e em execução.

Passo 1: Crie o arquivo docker-compose.yml

Na raiz do seu projeto (a pasta que você clonou do seu fork), crie um arquivo chamado docker-compose.yml e cole o seguinte conteúdo:

version: '3.9' services: latex: # Imagem completa do TeX Live, inclui todos os pacotes que você pode precisar image: texlive/texlive-full:latest container_name: tcc_latex_env working_dir: /app volumes: # Mapeia a pasta atual do projeto para o diretório /app dentro do container - .:/app # Comando para manter o container rodando em segundo plano command: tail -f /dev/null

Passo 2: Utilizando o Ambiente

Com o arquivo salvo, você pode gerenciar o ambiente com os seguintes comandos no seu terminal, na raiz do projeto:

  1. Iniciar o ambiente:
    docker-compose up -d
  2. Compilar o documento:
    Para compilar o arquivo main.tex, execute o comando pdflatex dentro do container. Pode ser necessário rodar mais de uma vez para gerar referências e sumário corretamente. docker-compose exec latex pdflatex main.tex
  3. Parar o ambiente:
    Quando terminar de usar, pare e remova o container. docker-compose down
Integração com VS Code

Se você tem a extensão "Dev Containers" do VS Code, ele pode detectar automaticamente seu arquivo docker-compose.yml e oferecer para reabrir o projeto dentro do container, dando a você uma experiência totalmente integrada, similar ao Codespaces, mas rodando localmente.

Capítulo 4

Opção 2: Ambiente na Nuvem com GitHub Codespaces

O GitHub Codespaces cria um ambiente de desenvolvimento completo que roda na nuvem e é acessado pelo seu navegador. É uma ótima opção para garantir que todos no grupo tenham o mesmo ambiente, sem precisar instalar nada localmente.

Passo 1: Configurar o Dev Container

A configuração do ambiente é feita através de um arquivo chamado devcontainer.json.

  1. No seu repositório do GitHub, crie uma pasta chamada .devcontainer.
  2. Dentro dela, crie um arquivo chamado devcontainer.json.
  3. Cole o seguinte conteúdo no arquivo. Ele instrui o Codespaces a usar uma imagem base e instalar o conjunto completo de ferramentas TeX Live.
{ "name": "LaTeX Codespace", "image": "mcr.microsoft.com/devcontainers/base:ubuntu", "features": { "ghcr.io/rocker-org/devcontainer-features/texlive:1": { "scheme": "full" } }, "customizations": { "vscode": { "extensions": [ "james-yu.latex-workshop" ] } } }

Este arquivo faz três coisas importantes: usa uma imagem base do Ubuntu, instala a distribuição TeX Live completa e já instala a extensão LaTeX Workshop para você.

Passo 2: Iniciar o Codespace

  1. Vá para a página principal do seu repositório no GitHub.
  2. Clique no botão verde "<> Code".
  3. Vá para a aba "Codespaces" e clique em "Create codespace on main".
  4. Aguarde o GitHub configurar seu ambiente. Isso pode levar alguns minutos na primeira vez.

Passo 3: Compilando na Nuvem

Uma vez que o Codespace estiver pronto, ele abrirá uma instância do VS Code no seu navegador. O processo para criar e compilar seu arquivo .tex é exatamente o mesmo do ambiente local, pois a extensão LaTeX Workshop já estará instalada e configurada.

Capítulo 5

Estrutura de um Documento ABNT com abntex2

O pacote abntex2 é uma implementação das normas da ABNT para LaTeX. Ele simplifica enormemente a formatação de trabalhos acadêmicos.

Abaixo, um modelo inicial para um trabalho de TCC. Crie um arquivo .tex com este conteúdo e compile-o para ver a estrutura que ele gera.

\documentclass[ 12pt, a4paper, oneside, brazil ]{abntex2} \usepackage[utf8]{inputenc} \usepackage{graphicx} % Para incluir imagens % --- Informações do Documento --- \titulo{Título do Trabalho} \autor{Nome Completo do Autor} \local{Cidade} \data{\today} \instituicao{ Instituição de Ensino \par Curso de Análise e Desenvolvimento de Sistemas } \orientador{Prof. Dr. Nome do Orientador} % --- Início do Documento --- \begin{document} % --- Elementos Pré-Textuais --- \imprimircapa \imprimirfolhaderosto \begin{resumo} Este é o resumo do seu trabalho... \end{resumo} \begin{abstract} This is the abstract of your work... \end{abstract} \tableofcontents % Sumário % --- Elementos Textuais --- \textual \chapter{Introdução} Aqui começa a introdução do seu trabalho. Você pode usar o comando \verb|\cite{}| para citar referências. \chapter{Desenvolvimento} \section{Seção 1} Conteúdo da seção 1. \section{Seção 2} Conteúdo da seção 2. \chapter{Conclusão} Considerações finais do trabalho. % --- Elementos Pós-Textuais --- \postextual \bibliography{referencias.bib} % Arquivo de referências \end{document}
Próximos Passos

Para que as referências funcionem, você precisará criar um arquivo referencias.bib e usar um gerenciador como JabRef ou Zotero para formatar suas citações no formato BibTeX.
