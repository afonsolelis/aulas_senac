1. Simplificação de Expressões Booleanas

Simplificar uma expressão booleana significa reduzi-la a uma forma equivalente com menos termos ou operadores. Isso torna o código mais legível, eficiente e, no mundo do hardware, resulta em circuitos mais baratos e rápidos.

Principais Propriedades
  • Comutativa: A ordem dos operandos não importa. A + B = B + A e A . B = B . A.
  • Associativa: O agrupamento dos operandos não importa. A + (B + C) = (A + B) + C.
  • Distributiva: Um operador "se distribui" sobre outro. A . (B + C) = A.B + A.C.
  • Identidade: Operar com o elemento neutro mantém o valor. A + 0 = A e A . 1 = A.
  • Idempotência: Operar uma variável com ela mesma resulta nela mesma. A + A = A e A . A = A.
  • Absorção: Uma expressão maior é "absorvida" por uma menor. A + A.B = A e A . (A + B) = A.
  • Leis de De Morgan: Essenciais para simplificar negações. !(A + B) = !A . !B e !(A . B) = !A + !B.
Exemplo Prático de Simplificação

Vamos simplificar a expressão F = (A + B).(A + C) passo a passo:

  1. Aplicar a Propriedade Distributiva:
    F = A.A + A.C + B.A + B.C
  2. Aplicar a Idempotência (A.A = A):
    F = A + A.C + B.A + B.C
  3. Aplicar a Absorção (A + A.C = A):
    F = A + B.A + B.C
  4. Aplicar a Absorção novamente (A + B.A = A):
    F = A + B.C
Conclusão: A expressão complexa (A + B).(A + C) é perfeitamente equivalente à expressão simples A + B.C.

2. Introdução aos Circuitos Lógicos

A Álgebra Booleana é a linguagem usada para projetar circuitos digitais, os blocos de construção de todo hardware moderno. Cada operador lógico corresponde a uma "porta" (gate) física.

Quando você escreve if (user.is_admin and user.is_active), o processador está, em um nível muito baixo, usando portas lógicas AND para avaliar essa condição.

3. Operadores Bitwise em Python

Enquanto operadores lógicos (and, or) trabalham com valores booleanos (True/False), os operadores bitwise (&, |, ^) trabalham diretamente nos bits de números inteiros.

Exemplo:

Se a = 5 (binário 0101) e b = 3 (binário 0011):

  • a & b (AND bit a bit) resulta em 1 (0001)
  • a | b (OR bit a bit) resulta em 7 (0111)
  • a ^ b (XOR bit a bit) resulta em 6 (0110)
Caso de Uso: Gerenciando Permissões

Bitwise é extremamente eficiente para armazenar e verificar um conjunto de opções ou permissões. Cada permissão é uma potência de 2, representando um bit específico.


PERM_LEITURA = 1  # 001
PERM_ESCRITA = 2  # 010
PERM_EXEC    = 4  # 100

# Concedendo permissões de leitura e execução
permissoes_usuario = PERM_LEITURA | PERM_EXEC  # Resultado: 5 (101)

# Para verificar uma permissão, usamos o operador AND (&)
pode_ler = (permissoes_usuario & PERM_LEITURA) > 0  # True
pode_escrever = (permissoes_usuario & PERM_ESCRITA) > 0 # False

4. Exercícios de Fixação

  1. Simplifique a expressão: A + A.B
    Ver resposta
    Resultado: A, pela propriedade da absorção.
  2. Simplifique a expressão: A.(A + B)
    Ver resposta
    Resultado: A, também pela absorção.
  3. Use as Leis de De Morgan para simplificar: not (A or B)
    Ver resposta
    Fica not A and not B.
  4. Desenhe o circuito lógico para a expressão: F = A.B + C
    Ver resposta
    Primeiro, uma porta AND para A e B. A saída dessa AND entra em uma porta OR junto com C.
  5. Qual o resultado de 10 & 12 em bitwise? (10 = 1010, 12 = 1100)
    Ver resposta
    1010 & 1100 = 1000, que em decimal é 8.
  6. Qual o resultado de 10 | 12 em bitwise?
    Ver resposta
    1010 | 1100 = 1110, que em decimal é 14.
  7. Simplifique: (A+B).(A+not B)
    Ver resposta
    Usando a identidade (X+Y).(X+Z)=X+Y.Z, fica A + B.not B, ou seja, A + 0. Resultado: A.
  8. Use De Morgan em: not (A.B)
    Ver resposta
    Fica not A + not B ou, em notação de programação, not A or not B.
  9. Desenhe o circuito para: F = (A+B).C
    Ver resposta
    Primeiro, uma porta OR para A e B. Depois, a saída dela entra em uma porta AND junto com C.
  10. Para que serve o operador bitwise XOR (^)? Dê um exemplo.
    Ver resposta
    O XOR retorna 1 quando os bits são diferentes. Exemplo: 5 ^ 3 equivale a 0101 ^ 0011 = 0110, que resulta em 6.
  11. Simplifique: A + not A.B
    Ver resposta
    Aplicando a distributiva, A + not A.B = (A + not A).(A + B) = 1.(A + B). Resultado: A + B.
  12. Simplifique: A.B + A.B.C
    Ver resposta
    Fatorando A.B, temos A.B.(1 + C). Como 1 + C = 1, sobra A.B.
  13. Desenhe o circuito para F = not(A.B). Que porta é essa? (NAND)
    Ver resposta
    É uma porta AND seguida de negação na saída. Esse circuito é uma porta NAND.
  14. Como representar as permissões "Leitura" e "Escrita" juntas usando o exemplo bitwise?
    Ver resposta
    Usando PERM_LEITURA | PERM_ESCRITA, ou seja, 1 | 2 = 3 (011).
  15. Qual o resultado de not A or (A and B)?
    Ver resposta
    Pela distributiva, not A or (A and B) = (not A or A).(not A or B). Isso vira 1.(not A or B), então o resultado é not A or B.
  16. Verifique se A + (B.C) é igual a (A+B).(A+C).
    Ver resposta
    Sim. Pela distributiva da álgebra booleana, (A+B).(A+C) simplifica para A + B.C.
  17. Desenhe o circuito para F = A ^ B (XOR).
    Ver resposta
    Use uma porta XOR com entradas A e B. A saída é 1 apenas quando as entradas forem diferentes.
  18. Em Python, como verificar se um número é par usando operadores bitwise? (Dica: num & 1)
    Ver resposta
    Basta testar se o último bit é 0: num & 1 == 0. Se for verdadeiro, o número é par.
  19. Simplifique a expressão (A + not B).(B + C) + B.
    Ver resposta
    Expandindo: A.B + A.C + not B.B + not B.C + B. Como not B.B = 0, fica A.B + A.C + not B.C + B. Pela absorção, B + A.B = B e B + not B.C = B + C. Resultado final: B + C + A.C, que simplifica para B + C.
  20. Crie uma função em Python que recebe um inteiro e verifica se o 3º bit (da direita para a esquerda, valor 4) está ativo.
    Ver resposta
    Exemplo: 
    def terceiro_bit_ativo(num):
  return (num & 4) != 0
