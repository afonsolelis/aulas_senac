1) Objetivo da aula

Esta aula conecta dois mundos: a lógica da programação e o funcionamento interno do computador. A ideia é parar de escrever código "no chute" e entender o que realmente acontece quando você usa comandos simples como input(), print(), soma, multiplicação e conversão de tipos.

O que você deve sair sabendo

  • Como CPU, RAM e armazenamento se relacionam.
  • Como variáveis funcionam em alto nível.
  • Por que tipo de dado muda o resultado de uma operação.
  • Como transformar entrada de texto em número para calcular.

2) Metáfora da cozinha: CPU, RAM e armazenamento

O slide usa uma metáfora excelente para iniciantes:

  • Chef = CPU: executa instruções muito rápido, mas não guarda contexto por conta própria.
  • Bancada = RAM: área de trabalho rápida onde ficam dados usados no momento.
  • Dispensa = HD/SSD: guarda dados por longo prazo, porém com acesso mais lento.

Leitura didática dessa metáfora

Quando você abre um programa, dados saem do armazenamento e vão para RAM. A CPU trabalha em cima do que está na RAM. Ao salvar um arquivo, você manda o resultado da RAM de volta para armazenamento permanente.

Regra prática: CPU e RAM são equipe de execução; HD/SSD é arquivo permanente.

3) Fluxo da informação: teclado, memória, CPU e monitor

No fluxo apresentado em aula, a sequência conceitual é:

  1. Usuário digita no teclado (entrada).
  2. Valor é armazenado em memória (RAM).
  3. CPU lê esse valor, processa e escreve resultado na RAM.
  4. Sistema exibe no monitor (saída).

Isso ajuda a entender que print() não é “mágica”: é apenas uma instrução de saída de dados que já passaram por memória e processamento.

Evite imaginar a CPU conversando diretamente com tudo ao mesmo tempo. Na prática, há camadas de mediação via memória e sistema.

4) Variáveis como caixas etiquetadas

Variável é um nome que aponta para um valor. No modelo da aula, pense em uma "caixa" com etiqueta:

nome = "Afonso"
idade = 30

O que isso significa

  • nome guarda texto.
  • idade guarda número.
  • O programa usa o nome da variável para acessar o valor depois.

Boas práticas iniciais

  • Use nomes claros e sem abreviações confusas.
  • Prefira snake_case em Python (ex.: idade_usuario).
  • Evite nomear variável igual a função nativa (input, list, str).

5) Como o computador encontra dados: ideia de hash

O slide explica de forma intuitiva que o computador não procura uma variável "olhando gaveta por gaveta". Em estruturas internas, ele usa estratégia de mapeamento para encontrar rapidamente uma posição associada a uma chave.

Por que isso importa para você

  • Ajuda a entender por que acesso a valores pode ser rápido.
  • Prepara terreno para dicionários em Python.
  • Mostra que nomes em alto nível são traduzidos internamente em referências e endereçamento.
Nesta fase, basta dominar a ideia: existe um mecanismo para localizar dados com eficiência sem varrer tudo.

6) Ciclo da CPU: fetch, decode, execute

Todo processamento passa por um ciclo básico:

  • Fetch: buscar instrução.
  • Decode: interpretar instrução.
  • Execute: executar instrução.

Quando você escreve uma linha simples em Python, o interpretador transforma isso em várias operações menores. É por isso que, para a máquina, mesmo tarefas simples são uma sequência de microetapas.

Programar bem é escrever instruções claras para que esse ciclo ocorra sem ambiguidades.

7) Entrada e saída em Python: input e print

Dois comandos fundamentais da aula:

comida = input("O que você quer? ")
print("Saindo um " + comida)

Interpretação correta

  • input() lê do usuário e devolve texto (tipo str).
  • Esse texto é armazenado em variável.
  • print() exibe uma saída usando os valores atuais das variáveis.
Erro clássico: esquecer que input() retorna texto e tentar operar matematicamente sem conversão.

8) Tipos de dados e por que isso importa

A aula diferencia três tipos básicos:

  • String (str): texto. Ex.: "5".
  • Inteiro (int): número sem parte decimal. Ex.: 5.
  • Real (float): número com decimal. Ex.: 5.0.

Exemplo-chave do slide

Expressão Interpretação Resultado
"5" + "5" Concatenação de texto "55"
5 + 5 Soma numérica 10

Mesmo símbolo (+), comportamento diferente dependendo do tipo.

9) Conversão de tipos: int e float

Para calcular com dados digitados pelo usuário, converta texto para número.

texto = input("Digite um número: ")
numero = int(texto)

idade = int(input("Qual sua idade? "))

Quando usar cada função

  • int() para números inteiros.
  • float() para valores com decimal (preço, altura, média etc.).

Tratando erro de entrada (primeiro contato)

Se o usuário digitar algo inválido, a conversão falha. Neste começo, a orientação é instruir o usuário com mensagens claras sobre o formato esperado.

Pensamento de qualidade desde já: valide entrada sempre que possível.

10) Operações matemáticas e cálculo real

Exemplo do slide:

preco = float(input("Preço: "))
desconto = preco * 0.10
final = preco - desconto

print(f"Final: {final}")

Operadores fundamentais

  • + soma
  • - subtração
  • * multiplicação
  • / divisão (resultado float)

Dica didática

Divida o problema em variáveis intermediárias (desconto, final) para facilitar leitura, depuração e explicação da lógica.

11) Como resolver os 20 desafios da aula

Os desafios foram planejados para fortalecer 4 competências:

  • Entrada e saída.
  • Conversão de tipos.
  • Operações aritméticas.
  • Organização do raciocínio em passos.

Estratégia única para quase todos

  1. Ler dados com input().
  2. Converter com int() ou float().
  3. Calcular com operadores.
  4. Mostrar resultado com print().

Template reutilizável

# 1) Entrada
valor1 = float(input("Digite o valor 1: "))
valor2 = float(input("Digite o valor 2: "))

# 2) Processamento
resultado = valor1 + valor2

# 3) Saída
print(f"Resultado: {resultado}")

Erros mais comuns nesses exercícios

  • Não converter entrada antes de calcular.
  • Usar vírgula no decimal ao digitar no Python padrão.
  • Trocar ordem da fórmula (ex.: IMC, Fahrenheit).
  • Esquecer de armazenar cálculo em variável.
Meta da aula: menos decorar sintaxe, mais entender o ciclo completo entrada → processamento → saída.

13) Resolução dos 20 exercícios (passo a passo)

Abaixo estão soluções diretas para os 20 desafios do slide. Estrutura usada: entrada, processamento e saída.

1) Escreva \"Olá, Mundo!\"

# Passo único: saída
print("Olá, Mundo!")

2) Peça o nome e responda \"Bem-vindo!\"

nome = input("Digite seu nome: ")      # Entrada
print("Bem-vindo,", nome)               # Saída

3) Some dois números inteiros

a = int(input("Primeiro número: "))    # Entrada + conversão
b = int(input("Segundo número: "))
soma = a + b                            # Processamento
print("Soma =", soma)                   # Saída

4) Peça um número e mostre o dobro

n = float(input("Digite um número: "))
dobro = n * 2
print("Dobro =", dobro)

5) Calcule a média de 3 notas

n1 = float(input("Nota 1: "))
n2 = float(input("Nota 2: "))
n3 = float(input("Nota 3: "))
media = (n1 + n2 + n3) / 3
print(f"Média = {media:.2f}")

6) Converta metros para centímetros (x100)

metros = float(input("Metros: "))
centimetros = metros * 100
print("Centímetros =", centimetros)

7) Antecessor e sucessor de um número

n = int(input("Número inteiro: "))
print("Antecessor =", n - 1)
print("Sucessor =", n + 1)

8) Área de um quadrado (L x L)

lado = float(input("Lado do quadrado: "))
area = lado * lado
print(f"Área = {area:.2f}")

9) Área de um retângulo (Base x Altura)

base = float(input("Base: "))
altura = float(input("Altura: "))
area = base * altura
print(f"Área = {area:.2f}")

10) Conversor: Real para Dólar (Divisão)

reais = float(input("Valor em R$: "))
cambio = float(input("Cotação do dólar: "))
dolar = reais / cambio
print(f"US$ {dolar:.2f}")

11) Ano de nascimento e idade (2026 - Ano)

ano_nasc = int(input("Ano de nascimento: "))
idade = 2026 - ano_nasc
print("Idade =", idade)

12) Salário com aumento de 10%

salario = float(input("Salário atual: "))
novo_salario = salario * 1.10
print(f"Novo salário = R$ {novo_salario:.2f}")

13) Desconto fixo de R$10,00

preco = float(input("Preço do produto: "))
final = preco - 10
print(f"Preço com desconto = R$ {final:.2f}")

14) Dias para horas (Dias * 24)

dias = int(input("Dias: "))
horas = dias * 24
print("Horas =", horas)

15) Minutos para segundos (Min * 60)

minutos = int(input("Minutos: "))
segundos = minutos * 60
print("Segundos =", segundos)

16) Calculadora de IMC (Peso / Altura²)

peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))
imc = peso / (altura ** 2)
print(f"IMC = {imc:.2f}")

17) Nome completo (nome + sobrenome)

nome = input("Nome: ")
sobrenome = input("Sobrenome: ")
completo = nome + " " + sobrenome
print("Nome completo:", completo)

18) Repetidor (palavra * número)

palavra = input("Palavra: ")
vezes = int(input("Quantidade de repetições: "))
print(palavra * vezes)

19) Velocidade média (Distância / Tempo)

distancia = float(input("Distância (km): "))
tempo = float(input("Tempo (h): "))
velocidade = distancia / tempo
print(f"Velocidade média = {velocidade:.2f} km/h")

20) Celsius para Fahrenheit (C * 1.8 + 32)

c = float(input("Temperatura em °C: "))
f = c * 1.8 + 32
print(f"Temperatura em °F = {f:.2f}")
Dica de estudo: execute cada exercício no Colab, altere os valores de entrada e observe como o resultado muda.
