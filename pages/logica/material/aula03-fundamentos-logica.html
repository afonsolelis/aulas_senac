1) Objetivo da aula

Consolidar a base de decisão em programação para turma iniciante: identificar tipos, comparar valores, construir estruturas com if, elif, else e combinar regras com and.

Escopo desta aula: bool, str, int, float, comparação, if/elif/else e and.

Número (int e float)

4) Operadores de comparação

Operador Leitura Exemplo Retorno
==igual10 == 10True
!=diferente10 != 5True
>maior7 > 9False
<=menor ou igual3 <= 3True

5) Estruturas condicionais: if, elif e else

nota = 6.5

if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")
O Python testa de cima para baixo e executa apenas o primeiro bloco verdadeiro.

6) Condição composta com and

idade = 20
pagou = True

if idade >= 18 and pagou:
    print("Entrada liberada")
else:
    print("Entrada negada")

and exige que todas as condições sejam verdadeiras.

7) Fluxograma da decisão lógica

Início

⬇

Ler dados

⬇

Condição do if?

Se SIM → executa bloco do if

Se NÃO → testa elif

Se elif for SIM → executa bloco do elif

Se elif for NÃO → executa bloco do else

Fim

# 34
n1 = float(input("Número 1: "))
n2 = float(input("Número 2: "))
op = input("Operação (+,-,*,/): ").strip()
if op == "+":
    print(n1 + n2)
elif op == "-":
    print(n1 - n2)
elif op == "*":
    print(n1 * n2)
elif op == "/":
    if n2 != 0:
        print(n1 / n2)
    else:
        print("Divisão por zero não permitida")
else:
    print("Operação inválida")
