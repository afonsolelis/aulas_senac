Aula 08 — Loops e Funções em Python

Loops automatizam tarefas repetitivas; funções organizam o código em blocos reutilizáveis. Juntos, formam a base de qualquer programa real.

1. O loop while

Repete o bloco de código enquanto a condição for True. A condição é verificada antes de cada execução.

while condição:
    # corpo — executado enquanto condição for True
    atualiza_variável  # FUNDAMENTAL para evitar loop infinito
contagem = 5
while contagem > 0:
    print(f"Contagem: {contagem}")
    contagem -= 1        # mesmo que: contagem = contagem - 1
print("🚀 Lançamento!")
Loop infinito: se a variável nunca for atualizada, a condição nunca se torna False e o programa trava. Use Ctrl+C para interromper no terminal/Colab.

2. O loop for

Percorre cada item de uma sequência: range(), lista, string, tupla, etc.

# range(inicio, fim, passo) — fim NÃO é incluído
for i in range(1, 6):
    print(i, end=" ")        # → 1 2 3 4 5

# lista
frutas = ["Maçã", "Banana", "Uva"]
for fruta in frutas:
    print(f"Tenho: {fruta}")

# string (letra por letra)
for letra in "Python":
    print(letra, end="-")     # → P-y-t-h-o-n-

3. break e continue

# break — sai do loop imediatamente
for i in range(10):
    if i == 5:
        break
    print(i, end=" ")          # → 0 1 2 3 4

# continue — pula esta iteração
for i in range(10):
    if i % 2 == 0:
        continue
    print(i, end=" ")          # → 1 3 5 7 9

4. Funções com def

Funções encapsulam um trecho de código com nome, entradas (parâmetros) e saída (return).

def calcular_media(n1, n2, n3):
    soma = n1 + n2 + n3
    media = soma / 3
    return media

# Chamando a função
resultado = calcular_media(7, 8, 9)
print(f"Média: {resultado:.1f}")   # → Média: 8.0
DRY — Don't Repeat Yourself: sempre que perceber que está copiando o mesmo bloco de código, é hora de criar uma função.

5. Funções + Loops juntos

def eh_par(n):
    return n % 2 == 0

numeros = [1, 2, 3, 4, 5, 6]
for n in numeros:
    icone = "✅" if eh_par(n) else "🔴"
    print(f"{icone} {n}")

def fatorial(n):
    resultado = 1
    for i in range(1, n + 1):
        resultado *= i
    return resultado

print(f"5! = {fatorial(5)}")   # 120
print(f"7! = {fatorial(7)}")   # 5040
print(f"10! = {fatorial(10)}") # 3628800

    for n in lista:
