1) Objetivo

Ao final desta aula, você será capaz de:

  • Construir tabelas verdade para expressões com qualquer número de variáveis
  • Classificar proposições como tautologia, contradição ou contingência
  • Validar equivalências lógicas usando tabelas verdade
  • Implementar geradores automáticos de tabelas em Python
Pré-requisitos: Conhecimento básico de lógica proposicional (conectivos ∧, ∨, ¬, →, ↔) e noções elementares de Python (variáveis booleanas, operadores and, or, not).

2) Definição

Uma tabela verdade é um método sistemático para enumerar todos os valores possíveis de verdade de uma proposição composta, dada todas as combinações possíveis de valores das variáveis que a compõem.

2.1 Aplicação prática

Considere um sistema de controle de acesso que libera entrada se:

  • O usuário tem credencial válida E o horário está dentro do permitido
  • OU se o usuário é administrador

Formalmente: (Credencial ∧ Horário) ∨ Administrador

A tabela verdade permite verificar o comportamento do sistema para todas as combinações possíveis de credencial, horário e tipo de usuário — essencial para validar regras de negócio antes da implementação.

2.2 Estrutura

  • Colunas de entrada: variáveis proposicionais (P, Q, R...)
  • Colunas intermediárias: subexpressões (útil para expressões complexas)
  • Coluna de saída: valor final da expressão

3) Regra 2ⁿ

O número de linhas de uma tabela verdade é dado por:

2n

n = número de variáveis distintas

3.1 Fundamentação

Cada variável booleana assume exatamente dois valores: Verdadeiro (V) ou Falso (F). Para n variáveis independentes, o número total de combinações é o produto cartesiano de n conjuntos binários: 2 × 2 × ... × 2 = 2ⁿ.

3.2 Exemplos

  • 1 variável: 2¹ = 2 linhas
  • 2 variáveis: 2² = 4 linhas
  • 3 variáveis: 2³ = 8 linhas
  • 4 variáveis: 2⁴ = 16 linhas

3.3 Algoritmo de preenchimento

Para organizar as colunas de entrada, adote o seguinte padrão:

P Q R
VVV
VVF
VFV
VFF
FVV
FVF
FFV
FFF
Padrão: A primeira coluna alterna a cada 2ⁿ⁻¹ linhas, a segunda a cada 2ⁿ⁻², e assim por diante, até a última coluna que alterna a cada linha (V, F, V, F...).

Equivalência útil: P → Q ≡ ¬P ∨ Q. Esta transformação é frequentemente usada em implementação de regras condicionais em código.

5) Classificação de Proposições

Tautologia

Proposição cujo valor lógico é sempre verdadeiro, independentemente dos valores das variáveis.

Exemplo: P ∨ ¬P

Identificação: coluna final contém apenas V.

Contradição

Proposição cujo valor lógico é sempre falso, independentemente dos valores das variáveis.

Exemplo: P ∧ ¬P

Identificação: coluna final contém apenas F.

Contingência

Proposição que pode ser verdadeira ou falsa, dependendo dos valores das variáveis.

Exemplo: P ∧ Q

Identificação: coluna final contém V e F.

5.1 Procedimento de classificação

  1. Construa a tabela verdade completa
  2. Examine exclusivamente a coluna final
  3. Aplique o critério:
    • Apenas V → Tautologia
    • Apenas F → Contradição
    • V e F misturados → Contingência

7.3 Classificador automático

def classificar_proposicao(resultados: list[bool]) -> str:
    """Retorna 'Tautologia', 'Contradição' ou 'Contingência'."""
    if all(resultados):
        return "Tautologia"
    elif not any(resultados):
        return "Contradição"
    else:
        return "Contingência"

# Exemplo
resultados = [True, False, True, True]
print(classificar_proposicao(resultados))  # Contingência

7.4 Gerador genérico com itertools

from itertools import product

def gerar_tabela_verdade(n: int, expressao: callable) -> None:
    """
    Gera tabela verdade para n variáveis.
    
    Args:
        n: número de variáveis
        expressao: função que recebe n booleanos e retorna um booleano
    """
    combinacoes = list(product([True, False], repeat=n))
    
    cabecalho = " | ".join([f"V{i}" for i in range(n)]) + " | Resultado"
    print(cabecalho)
    print("-" * len(cabecalho))
    
    resultados = []
    for valores in combinacoes:
        resultado = expressao(*valores)
        resultados.append(resultado)
        linha = " | ".join(str(int(v)) for v in valores)
        print(f"{linha} | {int(resultado)}")
    
    print(f"\nClassificação: {classificar_proposicao(resultados)}")

# Exemplo de uso:
expressao = lambda p, q: (p and q) or (not p)
gerar_tabela_verdade(2, expressao)
Nota: A função itertools.product gera o produto cartesiano automaticamente, eliminando a necessidade de loops aninhados manuais.

Metodologia:

  • Discussão em duplas (opcional)
  • Correção coletiva com justificativa formal

Kata 2: Lei de De Morgan

Verifique se ¬(P ∧ Q) é equivalente a ¬P ∨ ¬Q.

Solução
PQP∧Q¬(P∧Q)¬P¬Q¬P∨¬Q
VVVFFFF
VFFVFVV
FVFVVFV
FFFVVVV

Conclusão: Colunas idênticas → equivalentes.

Kata 3: Classificação Rápida

Classifique sem construir a tabela: (P ∧ ¬P) ∨ (Q ∨ ¬Q)

Solução

Análise:

  • P ∧ ¬P é contradição (sempre F)
  • Q ∨ ¬Q é tautologia (sempre V)
  • F ∨ V = V (sempre)

Classificação: Tautologia.

9) Erros Comuns

1. Número incorreto de linhas

Verifique sempre: 2ⁿ linhas. Um erro frequente é usar 6 linhas para 3 variáveis (o correto é 8).

2. Sequência de preenchimento incorreta

Siga o padrão: primeira coluna alterna a cada 2ⁿ⁻¹, segunda a cada 2ⁿ⁻², etc.

3. Interpretação equivocada do condicional

P → Q é falso apenas quando P=V e Q=F. Nos demais casos, é verdadeiro.

4. Negligenciar parênteses

(P ∧ Q) ∨ R ≠ P ∧ (Q ∨ R). A ordem de avaliação altera o resultado.

5. Classificar com base em colunas intermediárias

A classificação considera exclusivamente a coluna final.

Recomendação: Construa colunas intermediárias para cada subexpressão. Isso facilita a depuração e reduz erros de avaliação.

10) Exercícios

Nível Básico (1-5)

  1. Construa a tabela de P ∧ ¬Q e classifique.
  2. Construa a tabela de ¬(P ∨ Q) e classifique.
  3. Quantas linhas tem a tabela de P → (Q ∨ R)? Construa-a.
  4. Classifique: P ∨ ¬P
  5. Classifique: P ∧ ¬P

Nível Intermediário (6-12)

  1. Construa e classifique: (P ∧ Q) → R
  2. Verifique a equivalência: (P → Q) ≡ (¬Q → ¬P) (contrapositiva)
  3. Construa: P ↔ (Q ∧ R)
  4. Classifique: (P ∨ Q) ∧ (¬P ∨ ¬Q)
  5. Implemente em Python: (P or Q) and (not P or R)
  6. Traduza: "Se tenho dinheiro e tempo, então viajo ou estudo".
  7. Compare: ¬(P → Q) e P ∧ ¬Q

Nível Avançado (13-17)

  1. Prove: ((P → Q) ∧ (Q → R)) → (P → R) (silogismo hipotético)
  2. Verifique: P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R) (distributividade)
  3. Implemente um classificador automático para 2 variáveis em Python.
  4. Construa e classifique: (P ↔ Q) ↔ (R ↔ S)
  5. Prove: ¬(P ↔ Q) ≡ P ↔ ¬Q

Desafios (18-20)

  1. Lógica: A afirma "B é inocente", B afirma "C é culpado", C diz "A mente". Apenas um fala a verdade. Determine o culpado modelando com proposições.
  2. Python: Implemente um gerador que aceita expressões como string (ex: "(P and Q) or R") usando eval().
  3. Python: Crie um verificador de tautologias que retorna True se a expressão for tautológica.
Orientação: Dedique aproximadamente 15 minutos por exercício intermediário. Use Python para validação das respostas.
