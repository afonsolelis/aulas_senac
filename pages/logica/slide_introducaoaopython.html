O Computador é uma Cozinha

Para entender programação, imagine um restaurante.

O Chef (CPU)

Ele é super rápido, mas não lembra de nada. Ele só corta e cozinha o que está na frente dele.

A Bancada (RAM)

Onde os ingredientes (Dados) ficam enquanto o Chef trabalha. É rápido, mas se a luz acabar, tudo some!

A Dispensa (HD)

Lugar lento para guardar coisas pra sempre. O Chef (CPU) odeia ir até lá.

O Fluxo da Informação

O que acontece quando você digita algo?

Teclado Memória RAM CPU Memória RAM Monitor
Nota: A CPU nunca fala direto com o Monitor. Ela sempre escreve na RAM [print()], e a RAM manda pro Monitor.

Variáveis = Caixas Etiquetadas

Na Memória RAM, guardamos dados em gavetas numeradas.

O Vestiário Gigante

Imagine um vestiário com 1 bilhão de gavetas (Sua RAM).

Como achar a caixa "idade"?

O computador procura em cada gaveta?
Gaveta 1? Não. Gaveta 2? Não... Gaveta 5000? Não.

Isso demoraria milênios!

A Mágica do HASH

Transformamos a palavra "idade" em um número Matemático único.

Hash("idade") = 0x7ffd9b

O computador vai direto na gaveta certa!

As Comandas do Chef (CPU)

O Chef não pensa no prato pronto. Ele segue passos minúsculos chamados Instruções.

1. FETCH (Pegar)

O Chef pega uma comanda na memória.

2. DECODE (Ler)

O Chef lê: "MOVE Tomate TO Tábua".

3. EXECUTE (Fazer)

O Chef realmente move o tomate.

Seu código Python (a = 1 + 1) vira centenas dessas comandas!

Código vs Realidade


# O INPUT pega do teclado e joga na RAM
comida = input("O que você quer? ")

# O PRINT pega da RAM e joga na Tela
print("Saindo um " + comida)
Teclado RAM: caixa \"comida\" Monitor

A Forma da Caixa

O computador usa caixas diferentes para coisas diferentes.

String (Texto)

"5"

É um desenho. Ocupa mais espaço.

Int (Inteiro)

5

É matemática pura (Binário).

Float (Real)

5.0

Precisa de bits extras para a vírgula.

Por que "5" + "5" = "55"?

Instruções diferentes para tipos diferentes.

"5"
"5"

Instrução: CONCATENATE (Colar)

"55"
5
5

Instrução: ADD (Somar)

10

A Máquina de Conversão

Use int() para transformar a "caixa" de texto em "caixa" de número.


texto = input("Digite um número: ")  # Entra como Texto "10"
numero = int(texto)                  # Vira Número 10

# Ou direto:
idade = int(input("Qual sua idade? "))
\"10\" (String) int() 10 (Int)

Calculando na CPU


# A CPU busca 'preco' e multiplica por 0.10.
# Depois, guarda o resultado em 'desconto'.
preco = float(input("Preço: "))
desconto = preco * 0.10
final = preco - desconto

print(f"Final: {final}")
