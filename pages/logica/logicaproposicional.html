A Matemática das Sentenças

  • O que é uma Proposição?
  • Conectivos (E, OU, NÃO)

Proposição: V ou F

Uma frase declarativa que pode ser classificada como Verdadeira ou Falsa.

São Proposições

  • "O céu é azul." (V)
  • "2 + 2 = 5." (F)
  • "Hoje é sexta-feira." (V ou F)

NÃO São

  • "Que horas são?" (Pergunta)
  • "Limpe seu quarto!" (Ordem)
  • "x + 1 = 2" (Variável aberta)
Em Python: Proposição == Boolean (True / False)

Os Conectivos Lógicos

Nome Símbolo Python Fungão
Conjunção (E) ^ and Tudo tem que ser Verdade
Disjunção (OU) v or Basta um Verdadeiro
Negação (NÃO) ~ not Inverte (V vira F)

Do Papel para o PC

Como o computador entende "Se hoje faz sol E é Sábado..."


faz_sol = True
eh_sabado = False

# Conjunção (E)
if faz_sol and eh_sabado:
    print("Vamos à praia! 🏖️")
else:
    print("Netflix em casa. 📺")

# Saída: Netflix (Porque False ganha no AND)

O computador não entende o conceito de "Sol". Ele só entende True ou False.

Nós traduzimos o mundo real para Booleanos.

Expressões Compostas

Expressão: (P ^ Q) v ~R


p = True
q = True
r = False

# Tradução Direta
resultado = (p and q) or (not r)

print(f"Resultado: {resultado}")
# (True e True) ou (Não False)
# (True) ou (True)
# True
