Funções + Loops

Combinando os dois poderes

Por que precisamos de loops?

Imagine que o professor manda escrever 100 vezes na lousa…

Sem loop (jeito manual)
print("Eu não vou colar na prova.") print("Eu não vou colar na prova.") print("Eu não vou colar na prova.") print("Eu não vou colar na prova.") print("Eu não vou colar na prova.") print("Eu não vou colar na prova.") ... (mais 94 linhas iguais) ... print("Eu não vou colar na prova.")
98 linhas repetidas 😱
Com loop (jeito Python)
for i in range(100): print("Eu não vou colar na prova.")
2 linhas. Mesmo resultado. ✨
DRY — Don't Repeat Yourself. Um dos princípios fundamentais da programação.

while — Enquanto

In [1]: contagem = 5 while contagem > 0: print(f"Contagem: {contagem}") contagem = contagem - 1 print("🚀 Lançamento!")
Contagem: 5 Contagem: 4 Contagem: 3 Contagem: 2 Contagem: 1 🚀 Lançamento!
Como funciona?

O Python verifica a condição antes de cada repetição. Se for True, executa o bloco. Se for False, para.

Indentação obrigatória

Tudo que está dentro do while precisa ter 4 espaços (ou 1 tab). É assim que o Python sabe o que pertence ao loop.

Padrão clássico

inicializa variável → while condição → usa e modifica a variável

⚠️ Cuidado: Loop Infinito

In [2]: bateria = 100 while bateria > 0: print(f"Bateria: {bateria}%") bateria -= 20 # -= é o mesmo que bateria = bateria - 20 print("❌ Desligando...")
Bateria: 100% Bateria: 80% Bateria: 60% Bateria: 40% Bateria: 20% ❌ Desligando...
Loop infinito

Se a condição nunca se tornar False, o programa trava. Exemplo perigoso:

while True:
    print("Socorro!")  # nunca para!
Operadores de atribuição

x -= 1 = x = x - 1
x += 5 = x = x + 5
x *= 2 = x = x * 2

Como parar

No Colab/Terminal: Ctrl + C para interromper um loop infinito que travou.

for + range()

In [3]: # range(inicio, fim, passo) # fim NÃO é incluído! for i in range(1, 6): print(i, end=" ") print() # pula linha for i in range(0, 11, 2): print(i, end=" ") # só pares
1 2 3 4 5 0 2 4 6 8 10
range() — 3 formas
range(5) → 0, 1, 2, 3, 4
range(1, 6) → 1, 2, 3, 4, 5
range(0, 10, 2) → 0, 2, 4, 6, 8
end=" "

Por padrão, print() pula linha. Com end=" " ele coloca um espaço no lugar — útil para imprimir tudo na mesma linha.

Use for quando...

Você sabe quantas vezes quer repetir, ou tem uma coleção de itens para percorrer.

for percorrendo listas e strings

In [4]: frutas = ["Maçã", "Banana", "Uva"] for fruta in frutas: print(f"Tenho: {fruta}") print("---") # for também funciona em strings! for letra in "Python": print(letra, end="-")
Tenho: Maçã Tenho: Banana Tenho: Uva --- P-y-t-h-o-n-
Listas em Python

Listas são criadas com colchetes []. Podem guardar qualquer tipo de dado: números, textos, misturados.

f-strings

f"Tenho: {fruta}" — o f antes das aspas permite inserir variáveis entre {chaves} diretamente no texto.

for em string

Uma string é uma sequência de caracteres. O for percorre letra por letra, como se fosse uma lista de letras.

For aninhado — Tabela Verdade automática

In [5]: print("A | B | A and B") print("-" * 32) for a in [True, False]: for b in [True, False]: resultado = a and b print(f"{str(a):7} | {str(b):7} | {resultado}")
A | B | A and B -------------------------------- True | True | True True | False | False False | True | False False | False | False
For aninhado

Um for dentro de outro. Para cada iteração do externo, o interno completa todos os seus ciclos. 2 × 2 = 4 combinações.

Formatação de strings

{str(a):7} — o :7 define que o texto ocupa pelo menos 7 caracteres (preenche com espaços), alinhando colunas.

Conectando saberes

Usamos lógica booleana (and) dentro de um loop para gerar tabelas verdade automaticamente!

break e continue

In [6]: # break: PARA o loop imediatamente for i in range(10): if i == 5: break print(i, end=" ") print("\n---") # continue: PULA esta iteração for i in range(10): if i % 2 == 0: continue print(i, end=" ")
0 1 2 3 4 --- 1 3 5 7 9
break — Para tudo

Sai imediatamente do loop. Útil para "encontrei o que queria, pode parar".

continue — Pula um

Pula para a próxima iteração sem executar o restante do bloco. Útil para "não quero processar este item".

Operador %

i % 2 == 0 verifica se i é divisível por 2 (resto zero = par). 10 % 3 = 1, 9 % 3 = 0.

Funções — criando seus próprios comandos

def saudar (nome): ← palavra-chave
# corpo da função
mensagem = f"Olá, {nome}!"
return mensagem ← devolve resultado

# chamando a função
resultado = saudar ("Ana")
print(resultado) # Olá, Ana!
Para que serve?

DRY: escreve uma vez, usa em qualquer lugar. Sem função, você copiaria o mesmo código 10 vezes.

Parâmetros

São as "entradas" da função — os dados que ela precisa. (nome) é um parâmetro.

return

Devolve um valor para quem chamou a função. Se não tiver return, a função retorna None.

Primeira função: sem parâmetros

In [7]: def mostrar_boas_vindas(): print("╔══════════════════╗") print("║ Bem-vindo! ║") print("╚══════════════════╝") # Definir não executa — só chamar executa mostrar_boas_vindas() mostrar_boas_vindas() # reutilizando!
╔══════════════════╗ ║ Bem-vindo! ║ ╚══════════════════╝ ╔══════════════════╗ ║ Bem-vindo! ║ ╚══════════════════╝
Definir ≠ Executar

O bloco def apenas registra a função na memória. O código dentro só roda quando você chama a função com ().

Reutilização

Chamamos mostrar_boas_vindas() duas vezes. Se precisássemos 100 vezes, seriam 100 chamadas de 1 linha.

Nomenclatura

Use snake_case: palavras minúsculas separadas por _. Ex: calcular_media, eh_par.

Parâmetros e return

In [8]: def calcular_media(n1, n2, n3): soma = n1 + n2 + n3 media = soma / 3 return media # Testando com alunos diferentes media_ana = calcular_media(8, 7, 9) media_joao = calcular_media(5, 6, 4) print(f"Ana: {media_ana:.1f}") print(f"João: {media_joao:.1f}") if media_ana >= 6: print("Ana: Aprovada ✅") else: print("Ana: Reprovada ❌")
Ana: 8.0 João: 5.0 Ana: Aprovada ✅
Múltiplos parâmetros

Separados por vírgula. Você passa os valores na mesma ordem: calcular_media(8, 7, 9) → n1=8, n2=7, n3=9.

Usando o retorno

O valor retornado pode ser guardado em uma variável (media_ana = ...) ou usado diretamente em um if.

:.1f

Dentro de f-string, :.1f formata o número com 1 casa decimal. :.2f = 2 casas, :d = inteiro.

Funções + Loops juntos 🚀

In [9]: def eh_par(numero): return numero % 2 == 0 def classificar(numero): if numero % 2 == 0: return "par" return "ímpar" numeros = [1, 2, 3, 4, 5, 6] for n in numeros: tipo = classificar(n) icone = "✅" if eh_par(n) else "🔴" print(f"{icone} {n} é {tipo}")
🔴 1 é ímpar ✅ 2 é par 🔴 3 é ímpar ✅ 4 é par 🔴 5 é ímpar ✅ 6 é par
Separação de responsabilidades

eh_par() verifica paridade. classificar() retorna o texto. O for itera. Cada parte faz uma coisa só.

Ternário inline

"✅" if eh_par(n) else "🔴" — retorna o primeiro valor se verdadeiro, o segundo se falso. Tudo em uma linha.

Boas práticas

Funções pequenas, com nome claro, que fazem uma coisa só. Código assim é fácil de testar e reutilizar.

Resumo — Guia rápido

while — use quando não sabe quantas vezes
while condição:
    corpo
    atualiza variável
for — use quando sabe o que percorrer
for item in sequência:
    corpo
# range, lista, string...
break e continue
break # sai do loop
continue # pula esta iteração
def / return
def nome(p1, p2):
    resultado = ...
    return resultado
"Loops evitam repetição de execução. Funções evitam repetição de código. Juntos, são a base de qualquer programa real."
