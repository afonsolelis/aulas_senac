Lógica no Dia a Dia

Programar é transformar decisões em passos claros.

Exemplo 1
Se está chovendo, levo guarda-chuva.
Exemplo 2
Se nota >= 7, está aprovado.
Exemplo 3
Se login e senha corretos, liberar acesso.

Tipos de Dados Essenciais

Booleano

True ou False

String

Texto com aspas

Número

int e float

Booleanos na Prática

tem_ingresso = True
porta_aberta = False

print(tem_ingresso)
print(porta_aberta)
Booleano responde: sim/não, verdadeiro/falso.
Toda estrutura if depende de um resultado booleano.

Strings na Prática

usuario = "admin"
print(usuario == "admin")
print(usuario == "Admin")

nome = input("Nome: ").strip()
  • String diferencia maiúscula de minúscula.
  • .strip() remove espaços extras.
  • String é muito usada em login e validação.

Números e Conversão

idade_txt = input("Idade: ")
idade = int(idade_txt)

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
Erro comum: "18" >= 18
Correto: converter com int() ou float().

Estrutura if e else

saldo = 150

if saldo >= 100:
    print("Compra aprovada")
else:
    print("Saldo insuficiente")

1. Testa condição

2. Verdadeiro: bloco do if

3. Falso: bloco do else

Quando Usar elif

nota = 6.8

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")
O Python testa de cima para baixo e para na primeira condição verdadeira.

Condição Composta com and

idade = 20
pagou_ingresso = True

if idade >= 18 and pagou_ingresso:
    print("Entrada liberada")
else:
    print("Entrada negada")
Com and, todas as partes precisam ser verdadeiras.
True and True = True
True and False = False

Fluxograma: if, elif e else

Início
Ler dados (input)
Condição 1 é verdadeira?
Sim Ação do if
Não Testar elif
Condição 2 (elif) é verdadeira?
Sim Ação do elif
Não Ação do else
Fim

Exemplo 1: Login Simples

usuario = input("Usuário: ").strip().lower()
senha = input("Senha: ").strip()

if usuario == "aluno" and senha == "1234":
    print("Acesso permitido")
else:
    print("Acesso negado")

Exemplo 2: Faixa Etária

idade = int(input("Digite sua idade: "))

if idade <= 12:
    print("Criança")
elif idade <= 17:
    print("Adolescente")
elif idade <= 59:
    print("Adulto")
else:
    print("Idoso")

Exemplo 3: Desconto com and

preco = float(input("Preço: "))
clube = input("É do clube? (s/n): ").strip().lower() == "s"

if preco > 100 and clube:
    print("Desconto aplicado")
else:
    print("Sem desconto")

Erros Comuns de Iniciantes

Erro 1: usar = no lugar de ==.
Erro 2: comparar str com int.
Erro 3: esquecer : após if/elif/else.
Erro 4: errar a indentação do bloco.
