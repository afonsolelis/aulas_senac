Proposição: o que entra e o que não entra

Proposição é frase declarativa com valor lógico definido: Verdadeiro ou Falso.

São Proposições

  • "Belém é capital do Pará."
  • "7 é número par."
  • "Hoje é segunda-feira."

Não São Proposições

  • "Feche a porta." (ordem)
  • "Qual seu nome?" (pergunta)
  • "x + 2 = 9" (aberta, sem contexto)
No Python: proposição -> variável booleana (True/False)

Conectivos Fundamentais

Nome Símbolo Python Função
Conjunção ^ and Só é V se tudo for V
Disjunção v or É V se pelo menos um for V
Negação ~ not Inverte o valor lógico

Outros Conectivos Importantes

Condicional: P -> Q

Leitura: "Se P, então Q"

Em Python: (not p) or q

Falsa apenas quando P é V e Q é F.

Bicondicional: P <-> Q

Leitura: "P se e somente se Q"

Em Python: p == q

Verdadeira quando P e Q têm o mesmo valor.

Ordem de Avaliação

Sem parênteses, o Python segue a precedência:

1) not 2) and 3) or 
p = True
q = False
r = True

resultado = p or q and not r
# not r -> False
# q and False -> False
# p or False -> True

print(resultado)  # True

Da Linguagem Natural para Fórmula

Frase

"Vou ao cinema se tenho dinheiro e não estou cansado."

Tradução

P: tenho dinheiro

Q: estou cansado

C: vou ao cinema

C = P and (not Q)

Tabela-Verdade em Python

Expressão exemplo: (P and Q) or (not R)

valores = [True, False]

print("P Q R | (P and Q) or (not R)")
print("-" * 34)

for p in valores:
    for q in valores:
        for r in valores:
            resultado = (p and q) or (not r)
            print(p, q, r, "|", resultado)

Funções Lógicas em Python

Criando funções para reaproveitar condicional e bicondicional.

def implicacao(p, q):
    return (not p) or q

def bicondicional(p, q):
    return p == q

print(implicacao(True, False))   # False
print(implicacao(False, False))  # True
print(bicondicional(True, True)) # True
print(bicondicional(True, False))# False

Exemplo Prático: Sistema de Acesso

Regra: liberar se for professor ou aluno com matrícula ativa.

eh_professor = False
matricula_ativa = True
eh_aluno = True

liberar = eh_professor or (eh_aluno and matricula_ativa)

if liberar:
    print("Acesso liberado")
else:
    print("Acesso negado")

Ponto-chave: parênteses evitam erro lógico.

Sempre explicite a intenção da regra de negócio.

Exemplo Prático: Regra de Bolsa

Condição: bolsa se media >= 8 e frequencia >= 80 ou vulnerabilidade social.

media = 7.5
frequencia = 90
vulnerabilidade_social = True

recebe_bolsa = (media >= 8 and frequencia >= 80) or vulnerabilidade_social

print("Recebe bolsa?", recebe_bolsa)  # True

Da Filosofia ao Computador

Origem da Lógica

  • Aristóteles formalizou regras de argumentação (silogismos).
  • Séculos depois, a lógica virou linguagem matemática.
  • Boole criou a álgebra booleana (V/F).

Chegada aos Computadores

  • Claude Shannon ligou lógica booleana a circuitos elétricos.
  • Portas lógicas implementam AND, OR e NOT em hardware.
  • Programação usa as mesmas ideias em software.

Onde a Lógica Proposicional é Usada

Apps e Sistemas

Login, permissões, filtros, validação de formulários e regras de negócio.

Eletrônica Digital

Processadores, memória e circuitos funcionam com portas lógicas.

IA e Dados

Regras de decisão, classificação e automações dependem de operações lógicas.
