As 3 Operações Fundamentais

Toda a lógica digital se baseia em apenas três operações.

AND (E)

Resultado é 1 somente se ambas as entradas forem 1.

A · B  |  A and B

OR (OU)

Resultado é 1 se ao menos uma entrada for 1.

A + B  |  A or B

NOT (NÃO)

Inverte o valor: 1 vira 0, 0 vira 1.

¬A  |  not A

Porta AND — Tabela Verdade

Saída 1 só quando ambas as entradas são 1. (Tomada em série: as duas chaves precisam estar ligadas.)

ABA · B

A = True
B = False

resultado = A and B   # False

# Só retorna True quando AMBOS forem True
print(True and True)   # True
print(True and False)  # False
print(False and False) # False

Porta OR — Tabela Verdade

Saída 1 quando ao menos uma entrada é 1. (Tomada em paralelo: basta uma chave estar ligada.)

ABA + B
000
011
101
111
 
A = False
B = True

resultado = A or B    # True

# Retorna False só quando AMBOS forem False
print(True or True)   # True
print(True or False)  # True
print(False or False) # False

Inverte o valor lógico. Uma entrada, uma saída — sempre o oposto. É o "negador".

Símbolos das Portas Lógicas

Cada porta tem um símbolo padronizado usado em diagramas de circuitos.

Da esquerda para a direita: AND, OR, NOT, NAND, NOR, XOR, XNOR

Porta NAND — NOT + AND

AND com saída invertida. Resultado é 0 só quando as duas entradas são 1.

AB¬(A·B)
001
011
101
110
 
def nand(a, b):
    return not (a and b)

print(nand(True, True))   # False
print(nand(True, False))  # True
print(nand(False, False)) # True
NAND é a porta mais usada em chips físicos — qualquer circuito pode ser construído apenas com NANDs!

Porta NOR — NOT + OR

OR com saída invertida. Resultado é 1 só quando ambas as entradas são 0.

AB¬(A+B)
001
010
100
110
 
def nor(a, b):
    return not (a or b)

print(nor(False, False)) # True
print(nor(True, False))  # False
print(nor(True, True))   # False
NOR também é universal — assim como NAND, dá para montar qualquer circuito usando só portas NOR.

Porta XOR — OU Exclusivo

Resultado é 1 quando as entradas são diferentes. Se forem iguais, resultado é 0.

ABA ⊕ B
000
011
101
110
 
def xor(a, b):
    return a != b  # True quando diferentes

print(xor(True, False))  # True
print(xor(True, True))   # False

# Em Python com inteiros (bitwise):
print(5 ^ 3)   # 6  →  0101 ^ 0011 = 0110
XOR é muito usado em criptografia — aplicar XOR duas vezes retorna o valor original!

Propriedades da Álgebra Booleana

Estas regras permitem simplificar e reescrever expressões lógicas.

Comutativa: A+B = B+A   A·B = B·A
Associativa: A+(B+C) = (A+B)+C
Distributiva: A·(B+C) = A·B + A·C
Identidade: A+0 = A   A·1 = A
Nulidade: A+1 = 1   A·0 = 0
Idempotência: A+A = A   A·A = A
Complemento: A+¬A = 1   A·¬A = 0
Absorção: A+A·B = A   A·(A+B) = A

Leis de De Morgan

As leis mais importantes para simplificar expressões com NOT.

1ª Lei

¬(A · B) = ¬A + ¬B

NOT de um AND vira OR dos NOTs

not (a and b) == (not a) or (not b)
2ª Lei

¬(A + B) = ¬A · ¬B

NOT de um OR vira AND dos NOTs

not (a or b) == (not a) and (not b)
Macete: inverta o operador (AND ↔ OR) e distribua o NOT para cada variável.

Como Simplificar Expressões — Método

Siga esta ordem de prioridade para simplificar qualquer expressão:

1
Aplique a Distributiva para expandir parênteses: A·(B+C) = A·B + A·C
2
Aplique Idempotência para eliminar repetições: A·A = A e A+A = A
3
Aplique Absorção para eliminar termos: A+A·B = A
4
Aplique Complemento se houver A e ¬A: A·¬A = 0 e A+¬A = 1
5
Aplique De Morgan para mover NOTs para dentro ou fora
6
Repita os passos até não conseguir mais simplificar

Exemplo Guiado 1 — Absorção

Simplifique: F = A + A·B

1
Expressão original: F = A + A·B
Temos A sozinho e A multiplicado por B
2
Coloque A em evidência usando Distributiva: F = A·(1 + B)
A·1 + A·B = A·(1+B)
3
Aplique Nulidade: 1 + B = 1
Qualquer coisa OR 1 é sempre 1
4
Aplique Identidade: A·1 = A
Resultado: F = A   — a lei da Absorção diretamente.

Exemplo Guiado 2 — Distributiva + Idempotência

Simplifique: F = (A + B)·(A + C)

1
Distributiva (expandir): F = A·A + A·C + B·A + B·C
2
Idempotência A·A = A: F = A + A·C + B·A + B·C
3
Absorção A + A·C = A: F = A + B·A + B·C
4
Absorção novamente A + B·A = A: F = A + B·C
Resultado: F = A + B·C

Exemplo Guiado 3 — De Morgan

Simplifique: F = ¬(¬A · B) + ¬(A + ¬B)

1
Aplique 1ª lei de De Morgan ao primeiro termo: ¬(¬A · B) = A + ¬B
2
Aplique 2ª lei de De Morgan ao segundo: ¬(A + ¬B) = ¬A · B
3
Substitua: F = (A + ¬B) + (¬A · B)
4
Distributiva em (¬A · B) com A: F = A + ¬B + ¬A·B
Depois Absorção: ¬B + ¬A·B = ¬B + ¬A
5
Juntando: F = A + ¬A + ¬B → Complemento: A + ¬A = 1
Resultado: F = 1 — sempre verdadeiro!

Operadores Bitwise — O que são?

Aplicam a lógica booleana bit a bit em números inteiros — não no valor como um todo.

Número 5 em binário
0101

bit 3   bit 2   bit 1   bit 0

(4·0) + (4·1) + (2·0) + (1·1) = 5

Número 3 em binário
0011

bit 3   bit 2   bit 1   bit 0

(4·0) + (4·0) + (2·1) + (1·1) = 3

Os operadores bitwise comparam cada bit na mesma posição dos dois números.

Bitwise AND, OR, XOR, NOT

Com a = 5 (0101) e b = 3 (0011):

a = 5   # 0101
b = 3   # 0011

# AND (&): 1 só se ambos forem 1
a & b   # 0001 = 1

# OR  (|): 1 se ao menos um for 1
a | b   # 0111 = 7

# XOR (^): 1 se forem diferentes
a ^ b   # 0110 = 6

# NOT (~): inverte todos os bits
~a      # ...11111010 = -6
Opa (0101)b (0011)resultado
&010100110001 = 1
|010100110111 = 7
^010100110110 = 6
~0101—-6
~a em Python retorna -(a+1) por causa do complemento de dois.

Deslocamento de Bits — Shift

Deslocam todos os bits para a esquerda (<<) ou direita (>>) — equivale a multiplicar ou dividir por potência de 2.

n = 5   # 0000 0101

# Shift LEFT (<<): multiplica por 2^k
n << 1  # 0000 1010 = 10  (5 × 2)
n << 2  # 0001 0100 = 20  (5 × 4)

# Shift RIGHT (>>): divide por 2^k
n >> 1  # 0000 0010 = 2   (5 ÷ 2)
n >> 2  # 0000 0001 = 1   (5 ÷ 4)
Otimização: n << 1 é mais rápido que n * 2 — processadores fazem shifts nativamente.
Verificar se um número é par: n & 1 == 0 — examina apenas o último bit!

Bitwise na Prática — Sistema de Permissões

Cada bit representa uma permissão diferente. É exatamente assim que o Linux controla arquivos.

LEITURA = 1   # bit 0: 001
ESCRITA = 2   # bit 1: 010
EXECUCAO = 4  # bit 2: 100

# Dar permissão de leitura e execução (combinar com OR)
permissoes = LEITURA | EXECUCAO   # 001 | 100 = 101 = 5

# Verificar permissão (AND com a máscara)
tem_leitura  = bool(permissoes & LEITURA)   # 101 & 001 = 001 → True
tem_escrita  = bool(permissoes & ESCRITA)   # 101 & 010 = 000 → False
tem_execucao = bool(permissoes & EXECUCAO)  # 101 & 100 = 100 → True

# Remover uma permissão (AND com NOT da máscara)
permissoes = permissoes & ~EXECUCAO   # remove execução: 101 & 011 = 001

Exercício Guiado 1 — Simplificação

Resolva junto comigo: F = A·B + A·¬B

1
Observe que A aparece em ambos os termos. Coloque em evidência:
F = A·(B + ¬B)
2
Complemento: B + ¬B = 1 — uma variável OU seu oposto é sempre verdadeiro.
3
Identidade: A · 1 = A
Resultado: F = A
Interpretação: não importa o valor de B — o resultado depende só de A.

Exercício Guiado 2 — De Morgan em Python

Prove que not (x > 5 and y < 3) é igual a (x <= 5) or (y >= 3)

1
Identifique A = x > 5 e B = y < 3
2
Aplique a 1ª Lei: ¬(A · B) = ¬A + ¬B
3
¬(x > 5) → x <= 5  |  ¬(y < 3) → y >= 3
x, y = 4, 1
print(not (x > 5 and y < 3))   # True
print((x <= 5) or (y >= 3))    # True  ← mesmo resultado!

x, y = 7, 1
print(not (x > 5 and y < 3))   # False
print((x <= 5) or (y >= 3))    # False ← idêntico!

Exercício Guiado 3 — Par ou Ímpar com Bitwise

Escreva uma função que usa bitwise para verificar se um número é par ou ímpar.

Raciocínio:

1
Números pares têm o bit 0 = 0: 2 = 010, 4 = 100, 6 = 110
2
Números ímpares têm o bit 0 = 1: 1 = 001, 3 = 011, 5 = 101
3
Faça AND com 1 (máscara 0001) para isolar o último bit
def e_par(n):
    return (n & 1) == 0

def e_impar(n):
    return (n & 1) == 1

# Testes
for i in range(7):
    tipo = "par" if e_par(i) else "ímpar"
    print(f"{i} = {bin(i):>6} → {tipo}")
0=par, 1=ímpar, 2=par, 3=ímpar, 4=par...

Exercício Guiado 4 — Manipular Bits Individualmente

Aprenda a ativar, desativar e verificar um bit específico.

n = 0b00001010  # bits 1 e 3 ativos (decimal 10)

# Verificar se o bit k está ativo
def bit_ativo(n, k):
    return bool(n & (1 << k))

# Ativar o bit k (setar para 1)
def ativar_bit(n, k):
    return n | (1 << k)

# Desativar o bit k (setar para 0)
def desativar_bit(n, k):
    return n & ~(1 << k)

# Alternar o bit k (toggle)
def alternar_bit(n, k):
    return n ^ (1 << k)

print(bit_ativo(n, 1))    # True  (bit 1 = 1)
print(bit_ativo(n, 2))    # False (bit 2 = 0)
print(bin(ativar_bit(n, 2)))   # 0b1110
print(bin(desativar_bit(n, 1)))# 0b1000
