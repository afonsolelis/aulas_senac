Projeto Semestral

Diretrizes do Projeto Final

Disciplina: Introdução à Lógica | Ambiente obrigatório: Google Colab

Individual

Projeto feito por 1 aluno, com escopo reduzido e bem organizado.

Dupla

Projeto feito por 2 alunos, com divisão clara de tarefas e integração.

Trio

Projeto feito por 3 alunos, com escopo mais robusto e documentação curta.

Objetivo do Projeto

Construir um projeto completo em Python no Google Colab, aplicando os conhecimentos vistos até a aula de Portas Lógicas. O sistema deve resolver um problema real simples (educação, comércio, organização pessoal, jogos lógicos, automação de cálculos etc.).

Conteúdos obrigatórios que o projeto deve usar

Input e Output Variáveis e Tipos Operações Matemáticas Condicionais Tabelas Verdade Lógica Proposicional Álgebra Booleana Portas Lógicas
  • Pelo menos 2 menus de navegação no terminal.
  • Pelo menos 5 funcionalidades para projeto individual, 7 para dupla e 9 para trio.
  • Pelo menos 3 decisões lógicas usando operadores booleanos (and, or, not).
  • Pelo menos 1 simulação envolvendo portas lógicas (AND, OR, NOT, NAND, NOR, XOR ou XNOR).

Estrutura mínima do notebook (Colab)

  1. Capa com nome do projeto e integrantes.
  2. Descrição curta do problema e objetivo.
  3. Seção de funções principais.
  4. Seção de execução do menu principal.
  5. Testes com exemplos de entrada e saída.
  6. Conclusão: o que funcionou e o que pode evoluir.

Tema obrigatório: problema real da vida profissional

O projeto não deve ser um tema genérico inventado. Cada equipe deve identificar um problema real do próprio contexto de trabalho (ou estágio/rotina profissional) e criar a solução em cima desse cenário.

  • Exemplo: automatizar geração/comparação de cotações.
  • Exemplo: organizar envio e acompanhamento de logística.
  • Exemplo: validar pedidos, estoque ou regras de aprovação com lógica booleana.
  • Exemplo: automatizar conferências manuais repetitivas do dia a dia.

Critérios de avaliação sugeridos

  • Lógica e correção (40%): decisões corretas e fluxo consistente.
  • Aplicação dos conteúdos (30%): uso real dos tópicos da disciplina.
  • Organização do código (20%): variáveis claras e funções bem separadas.
  • Apresentação (10%): explicação objetiva do funcionamento no Colab.

Avaliação final: prova oral individual

A avaliação final do projeto será uma prova oral. O professor fará perguntas para cada aluno sobre o funcionamento do projeto.

  • Cada aluno deve explicar claramente a parte que desenvolveu.
  • As perguntas serão baseadas no código, na lógica e nas decisões do projeto.
  • Não basta só apresentar o resultado: é obrigatório demonstrar domínio da implementação.

Regras importantes

  • Não vale entregar somente exercícios soltos: deve ser um projeto integrado.
  • Não vale copiar projeto pronto da internet sem adaptação autoral.
  • Todo integrante deve conseguir explicar a lógica das principais partes.
