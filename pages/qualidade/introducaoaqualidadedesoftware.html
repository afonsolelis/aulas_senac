O que é Qualidade de Software?

Para o Usuário

"O software faz o que eu preciso, sem travar, sem erros e rápido."

+

Para o Dev

"O código é limpo, testável, manutenível e bem documentado."

"Qualidade não é um ato, é um hábito."

Aristóteles

Definição Formal

IEEE 610 (Institute of Electrical and Electronics Engineers)

"O grau em que um sistema, componente ou processo atende aos requisitos especificados e as necessidades ou expectativas do cliente ou usuário."

Requisitos Especificados

O que foi combinado que o software deve fazer.

Expectativas do Usuário

O que o usuário espera, mesmo que ninguém tenha escrito.

QA vs QC vs Teste

Três conceitos diferentes, frequentemente confundidos.

QA

Quality Assurance

Prevenção. Foco no processo.

"Estamos seguindo boas práticas para evitar defeitos?"

Proativo

QC

Quality Control

Detecção. Foco no produto.

"O software entregue atende aos requisitos?"

Reativo

Teste

Testing

Execução. Foco na verificação.

"Executar o software para encontrar defeitos."

Técnico

Analogia: Fábrica de Carros

QA

"Os engenheiros seguem o manual de montagem corretamente? Os parafusos são do tamanho certo?"

Garantir que o PROCESSO está correto.

QC

"O carro montado tem a pintura perfeita? Os freios funcionam? Algum defeito visível?"

Inspecionar o PRODUTO final.

Teste

"Ligar o carro, pisar no acelerador, frear bruscamente, testar o ar-condicionado."

EXECUTAR cenários para validar.

Instruções

  1. Acesse o repositório do projeto no GitHub.
  2. Clone o projeto na sua máquina.
  3. Analise o código e identifique problemas de qualidade.
  4. Classifique cada problema encontrado.

Classifique como:

  • Bug Erro que causa comportamento incorreto
  • Usabilidade Difícil de usar ou entender
  • Performance Lento ou ineficiente
  • Segurança Vulnerabilidade potencial

Setup do Ambiente (Windows)

Passo a passo para configurar o projeto Java.

1 Instalar o Scoop e Maven

Abra o PowerShell como administrador:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex

Depois instale o Java e o Maven:

scoop bucket add java
scoop install temurin-lts-jdk maven
mvn --version
2 Clonar e abrir no VS Code

No terminal, clone o repositório:

git clone https://github.com/afonsolelis/qualidade_software.git
code qualidade_software
3 Rodar o projeto com Maven

No terminal integrado do VS Code (Ctrl+`):

mvn clean install
mvn spring-boot:run
