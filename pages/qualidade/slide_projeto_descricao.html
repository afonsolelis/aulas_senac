Projeto Semestral

Gerenciador de Biblioteca Pessoal

Visão Geral

O objetivo deste projeto é desenvolver uma aplicação completa para cadastro e gerenciamento de livros de uma biblioteca pessoal, incluindo autenticação de usuários. A aplicação deve ser robusta, seguindo as melhores práticas de desenvolvimento e, principalmente, focada em qualidade e testabilidade.

O sistema deve permitir o CRUD de livros, o cadastro de novos usuários, com persistência em MongoDB e uma interface funcional que realize o gerenciamento de sessão.

Requisitos Técnicos

Backend
  • Spring Boot (Java)
  • MongoDB (NoSQL)
  • Arquitetura MVC
  • Testcontainers & VCR
  • Cadastro de Usuários
Frontend
  • Interface Web Funcional
  • Gerenciamento de Sessão
  • Design Responsivo
  • Experiência do Usuário (UX)
